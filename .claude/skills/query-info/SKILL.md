# 实时信息查询

## 适用场景

- 查询目的地天气；
- 查询需要联网获取的公开信息；
- 行程规划需要补充时效信息。

企业差旅政策使用 `ask-question`，个人历史使用 `memory-query`。

## 实现

- 入口：`script/agent.py` 中的 `InformationQueryAgent`；
- 天气：wttr.in；
- 一般搜索：DDGS；
- 返回：`query_type`、`query_success`、摘要和可用来源。

## 回答要求

1. 根据当前日期正确理解“今天、明天、下周”等相对时间；
2. 直接回答问题，避免重复描述搜索过程；
3. 不把搜索摘要包装成已核实的企业内部信息；
4. 信息不完整、来源失败或时间范围不可用时明确说明；
5. 保留可用来源，便于后续检查。
