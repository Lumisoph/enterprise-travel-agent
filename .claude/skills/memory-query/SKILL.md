# 用户记忆查询

## 适用场景

- “我去过哪些地方”；
- “上次去北京是什么时候”；
- “我保存过什么酒店偏好”。

## 实现

- 入口：`script/agent.py` 中的 `MemoryQueryAgent`；
- 依赖：调用方传入当前用户对应的 `MemoryManager`；
- 数据：行程历史、偏好和历史对话摘要。

## 回答要求

1. 只根据提供的当前用户记忆回答；
2. 没有相关记录时明确说明，不补造历史；
3. 多条记录优先按时间或类别整理；
4. 不在回答中泄露存储路径、内部标识或其他实现细节。
